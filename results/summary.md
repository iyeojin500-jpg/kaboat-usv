# Before(CASE1) vs After(CASE2) 결과

- Before CASE1: 단순 순차 + 독립 A* + 작업 완료 후 작업장(입고장) 복귀
- After  CASE2: OR-Tools VRP 후속 작업 선택 + Cooperative A* + 예약테이블 + 작업 완료 위치에서 연속 수행 (복귀는 선택)
- 주문 1건 = 입고 작업(입고장→RFID→저장구역 적치) + 출고 작업(저장구역 피킹→출고장), 출고는 입고 완료 후
- 공통: AMR 3대, 주문 1000건, seed=42, 발생간격 배율 1 (동일 주문·작업시간·RFID 결과)
- 부하: 주문 발생 257건/h vs Before 처리능력 55건/h
